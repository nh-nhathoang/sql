# LeetCode SQL 50 Solutions

This repository contains my solutions to the **LeetCode SQL 50** study plan, completed as part of my interview preparation.

The purpose of this repository is to strengthen SQL skills through practical database querying problems, covering common topics.

## Topics Covered

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* HAVING
* Aggregate Functions
* JOINs

  * INNER JOIN
  * LEFT JOIN
  * RIGHT JOIN
* Self JOIN
* UNION
* CASE Expressions
* Subqueries
* Common Table Expressions (CTEs)
* Window Functions
* Ranking Functions
* Date Functions

## Repository Structure

Each solution follows the format:

```text
<ProblemNumber>_<ProblemTitle>.sql
```

Example:

```text
0175_Combine_Two_Tables.sql
0181_Employees_Earning_More_Than_Their_Managers.sql
0550_Game_Play_Analysis_IV.sql
```

## Solution Format

Each SQL file contains the query submitted to LeetCode. The solutions are written for the LeetCode MySQL environment and focus on:

* Correctness
* Readability
* Efficient SQL practices
